# 微博热搜 Top 10

按以下步骤为用户查询并整理微博热搜：

1. 调用 `web_fetch` 抓取微博热搜接口：`https://weibo.com/ajax/side/hotSearch`。
   返回 JSON，榜单在 `data.realtime` 数组中（已按热度降序），每条含：
   - `word`：词条
   - `num`：热度值（可能没有）
   - `label_name`：榜单标签（"热"/"新"/"沸"/"荐"等，可能没有）
2. 若该接口失败或返回的 JSON 里没有 `data.realtime`，改用备用接口
   `https://weibo.com/ajax/statuses/hot_band`（榜单在 `data.band_list`，词条字段为 `word`，热度为 `num`）。
3. 两个接口都失败时，调用 `web_search` 搜索「微博热搜」，从结果中提取榜单。
4. 取前 10 条整理输出：词条 + 标签 + 热度值（用万或千为单位，保留一位小数）。
5. 列表末尾用一句话概括榜单主题分布（如娱乐 / 社会 / 体育占比）。
6. 若三条途径全部失败，直接告诉用户"暂时抓不到微博热搜"，并说明失败原因，不要编造榜单。

## 输出格式示例

```
🔥 微博热搜 Top 10

1. 现在就出发4 【新】 126.2万
2. 八仙 【热】 110.9万
3. 数字经济交出亮眼成绩单 103.1万

```
