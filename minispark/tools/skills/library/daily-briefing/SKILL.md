# 每日简报

按以下步骤为用户生成今日简报：

1. 使用 `web_search` 搜索当日重要新闻（按用户偏好领域）。
2. 查询今日天气（用户所在城市，从记忆中读取；若无则询问一次并记住）。
3. 从记忆中检索用户近期提到的待办或约定。
4. 将以上内容整理为简短列表（新闻 3 条 + 天气 + 待办），用 `memory_save` 记录"已推送 X 日简报"。
5. 通过当前通道回复结果。

## 输出格式示例

```
早安 ☀️ 今天是 2026-07-25

📰 今日要闻
1. ...
2. ...
3. ...

🌤 天气
北京 晴 28°C
